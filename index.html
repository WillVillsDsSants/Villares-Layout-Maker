Guia de Ferramentas

Tudo que você precisa saber para usar o modo CAD

╱
Linha
L

Cada segmento é um objeto independente. Você pode selecionar e apagar cada linha separadamente.

⌒
Polilinha
PL

Vários segmentos formam UM único objeto. Ideal para contornos de cômodos, paredes contínuas. Permite calcular área se fechada.

▭
Retângulo
REC

2 cliques (cantos opostos). Quando vira quadrado, fica verde e trava na proporção 1:1 automaticamente.

○
Círculo
C

Centro + raio. Útil para colunas, móveis circulares e cotas radiais.

◜
Arco
A

3 pontos: início, meio e fim. Para curvas e abertura de portas.

~
Spline
SPL

Curva suave passando pelos pontos. Diferente da polilinha que faz retas.

▨
Hachura
H

Preenche uma área com padrão de linhas paralelas. Clique para definir contorno e Enter para finalizar.

A
Texto
T

Adiciona anotações e legendas no desenho. Clique no canvas e digite o texto.

✥
Mover
M

Clique na ferramenta, depois clique no objeto que quer mover. Defina ponto base e destino.

⧉
Copiar
CO

Clique no objeto, defina origem e cole quantas cópias quiser. Esc para finalizar.

↻
Girar
RO

Use os botões rápidos no painel direito (-90° / +90°), ou clique e arraste para ângulo livre.

⊕
Escala
SC

Aumenta ou diminui o tamanho. Botões rápidos +10% / -10% no painel ou tamanho exato pelos campos.

⇄
Espelhar
MI

Cria reflexo do objeto. Use os botões Flip H ou Flip V para espelhar instantaneamente.

⊞
Offset
O

Cria cópia paralela a uma distância definida. Ótimo para fazer paredes paralelas.

✂
Cortar
TR

Apara linhas no ponto onde se cruzam com outras.

✕
Apagar
DEL

Remove o objeto selecionado. Use Ctrl+Z para desfazer.

Edição Rápida pelo Painel

Selecionou um objeto? O painel direito mostra todas as propriedades editáveis. Você não precisa entrar em modos diferentes para girar ou escalar.

1
Clique em qualquer objeto no canvas com a ferramenta Selecionar. As propriedades aparecem no painel direito instantaneamente.
2
Edite os campos diretamente: nome, dimensões, posição, ângulo. Tudo atualiza ao vivo enquanto você digita.
3
Use os botões de ação rápida na seção AÇÕES RÁPIDAS:
⟲ -90° / ⟳ +90° — Gira o objeto ⊕ +10% / ⊖ -10% — Aumenta/diminui ⇄ Flip H / ⇅ Flip V — Espelha ⧉ Duplicar — Faz uma cópia
4
Duplo clique em qualquer objeto para focar diretamente no campo Nome — pronto para renomear.
5
Arraste objetos selecionados diretamente no canvas para mover sem precisar de ferramenta.
